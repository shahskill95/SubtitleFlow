# Как получить EXE и APK SubtitleFlow

После обновления исходников GitHub Actions собирает установочные файлы автоматически.

## Windows EXE

1. Открой вкладку **Actions** репозитория: https://github.com/shahskill95/SubtitleFlow/actions
2. Выбери workflow **Windows EXE**.
3. Открой последний успешный запуск (зелёная галочка).
4. Внизу страницы в разделе **Artifacts** скачай `SubtitleFlow-Windows-x64`.
5. Распакуй ZIP и запусти `SubtitleFlow.exe`.

Это portable-сборка папкой, упакованная в ZIP, а не установщик MSI. Не удаляй соседние файлы и папки из распакованного комплекта: они нужны EXE для работы.

**FFmpeg:** должен быть установлен в Windows и доступен через PATH. Интернет нужен для первой загрузки модели Whisper и онлайн-перевода.

## Android APK

1. Открой вкладку **Actions** репозитория.
2. Выбери workflow **Android APK**.
3. Открой последний успешный запуск.
4. В разделе **Artifacts** скачай `SubtitleFlow-Android-debug`.
5. Распакуй ZIP и установи `app-debug.apk` на телефон. Android может попросить разрешить установку из этого источника.

Это debug APK для личного тестирования, не release APK для Google Play.

## Как понять, что сборка прошла

В Actions должен быть зелёный статус **Success** у соответствующего workflow. Красный статус означает ошибку сборки; открой запуск и проверь шаг, отмеченный красным.

## Важно

APK не запускает Whisper на телефоне. Android-приложение отправляет видео на включённый компьютер по доверенной локальной Wi-Fi сети; распознавание и перевод выполняются на Windows-ПК. Не публикуй адрес с временным ключом доступа.
