# История изменений

## 1.0.0 — 2026-11-24

- Первый комплект SubtitleFlow для Windows и Android.
- Распознавание аудио/видео с помощью OpenAI Whisper.
- Перевод сегментов на русский через Google Translate (`deep-translator`).
- Экспорт субтитров с тайм-кодами в SRT.
- Windows GUI на Tkinter.
- Android-клиент и мобильная веб-страница в локальной сети.
- Временный ключ доступа для LAN-сервера.
