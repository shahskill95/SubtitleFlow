# Участие в разработке

1. Создай fork репозитория и отдельную ветку для изменений.
2. Сохраняй совместимость с Python 3.11 и поддерживаемой конфигурацией Android-проекта.
3. Для исправлений логики добавляй тесты в `tests/`.
4. Перед pull request выполни:

   ```bash
   python -m unittest discover -s tests -v
   python -m compileall -q pc tests
   ```

5. В описании pull request укажи, что изменилось и как это проверялось. Не добавляй видео, SRT-файлы, модели Whisper, ключи или личные данные.
