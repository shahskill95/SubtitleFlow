# Безопасность

## Поддерживаемые версии

На текущем этапе поддерживается ветка `1.0.x`.

## Сообщение об уязвимости

Не публикуй рабочие ключи доступа, приватные видео, персональные данные или полные URL с параметром `?key=...` в публичных Issues. Передай описание уязвимости владельцу репозитория приватным способом.

## Сетевая модель и ограничения

- LAN-сервер по умолчанию слушает порт `8765` на сетевых интерфейсах компьютера.
- При каждом запуске создаётся случайный временный ключ; он нужен для доступа к мобильной странице и endpoint загрузки.
- Ключ маскируется в access-log консоли, но остаётся частью ссылки, которую пользователь копирует на телефон.
- Соединение по локальному HTTP не шифруется. В недоверенной Wi-Fi сети ключ и содержимое загрузки могут быть перехвачены.
- Используй приложение только в доверенной частной Wi-Fi сети.
- Не открывай порт `8765` в интернет и не настраивай проброс порта на роутере.
- Загруженное с телефона медиа временно записывается в системную временную папку Windows и удаляется после отправки ответа.
- Само видео не передаётся Google Translate; текст распознанной речи отправляется внешнему сервису перевода.
