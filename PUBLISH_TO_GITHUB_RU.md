# Как загрузить SubtitleFlow на GitHub

Эта инструкция нужна, чтобы опубликовать исходный код в своём GitHub-аккаунте.

## Вариант 1 — через сайт GitHub (без командной строки)

1. Войди в свой аккаунт на [github.com](https://github.com/).
2. Нажми **New repository**.
3. Название: `SubtitleFlow`.
4. Выбери **Public**, если хочешь открыть исходный код всем, или **Private**, если репозиторий должен быть только у тебя.
5. Не добавляй README, `.gitignore` или лицензию на сайте — они уже есть в проекте.
6. Нажми **Create repository**.
7. Распакуй ZIP-архив SubtitleFlow на компьютере.
8. В пустом репозитории нажми **uploading an existing file**.
9. Перетащи содержимое распакованной папки `SubtitleFlow` в окно загрузки (не сам ZIP-архив и не внешнюю папку целиком).
10. Дождись завершения загрузки, введи сообщение `Initial release: SubtitleFlow 1.0.0` и нажми **Commit changes**.

Проверь, что на главной странице репозитория видны `README.md`, папки `pc`, `android`, `tests` и файлы лицензии.

## Вариант 2 — через Git (если Git установлен)

Открой CMD в папке проекта и выполни:

```bat
git init
git add .
git commit -m "Initial release: SubtitleFlow 1.0.0"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/SubtitleFlow.git
git push -u origin main
```

В команде `git remote add origin` замени `ВАШ_ЛОГИН` на свой GitHub-логин. При запросе авторизации используй браузер или Git Credential Manager; не вставляй пароль GitHub в команду.

## Перед публикацией

- Не загружай личные видео, аудио и созданные `.srt`.
- Не публикуй URL с временным `?key=...`.
- Не добавляй пароли, токены и персональные данные.
- Проверь содержимое репозитория перед подтверждением загрузки.

## После загрузки

Открой `README.md` на GitHub. GitHub автоматически покажет его как главную страницу проекта. В дальнейшем можно создавать Releases, Issues и принимать предложения через вкладки репозитория.
