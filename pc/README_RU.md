# Windows-клиент SubtitleFlow

## Требования

- Windows 10/11 x64;
- Python 3.11;
- FFmpeg, добавленный в `PATH`; команда `ffmpeg -version` должна работать в CMD;
- интернет для загрузки модели Whisper и онлайн-перевода.

## Первый запуск

1. При необходимости установи Python 3.11 и FFmpeg.
2. Дважды запусти `setup_windows.bat`. Скрипт установит `openai-whisper` и `deep-translator`.
3. Дождись завершения установки. Первый запуск Whisper может скачать модель размером в сотни мегабайт.
4. Запусти `start_subtitleflow.bat`.
5. Выбери видео/аудио, язык и модель, затем нажми «Создать русские субтитры».

Файл `имя_медиа_ru.srt` сохранится рядом с исходным файлом.

## Подключение Android

Оставь приложение открытым. Скопируй полный адрес из блока «Подключение Android» и открой его на телефоне в Chrome в той же доверенной Wi-Fi сети. Не пересылай ссылку с временным ключом другим людям.

Либо собери нативный Android-клиент по инструкции `../android/README_BUILD_APK_RU.md`.
